# Interactive Sales Analytics Dashboard
📌 Project Overview

This project presents an Interactive Sales Analytics Dashboard designed to analyze sales performance and generate actionable business insights. The dashboard provides a clear overview of revenue, profit, sales channels, regional performance, and product-level trends.

By transforming raw sales data into visual insights, this project demonstrates how data visualization and business intelligence tools can support data-driven decision making.

# Project Objectives

Analyze overall sales performance and profitability

Identify top-performing products

Track monthly revenue trends

Compare sales channels performance

Understand regional revenue distribution

Provide interactive filters for deeper analysis
